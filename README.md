AI Legal Advisor Chatbot with Appointment Booking
Project Overview

This project is a full-stack web application that provides basic legal guidance through a chatbot and allows users to book appointments with lawyers online.

Features
AI-based chatbot for answering legal queries
Lawyer appointment booking system
REST API backend using Spring Boot
MySQL database integration
Responsive web interface
Tech Stack
Java
Spring Boot
MySQL
HTML, CSS, JavaScript
Maven
